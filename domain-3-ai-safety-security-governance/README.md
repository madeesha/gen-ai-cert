# 📕 Domain 3 · AI Safety, Security, and Governance (20%)

Domain 3 covers keeping GenAI systems safe and trustworthy. It covers:
- input and output safety controls (guardrails, hallucination control, prompt-injection defence)
- data security and privacy (network isolation, encryption, PII handling)
- governance and compliance (lineage, audit, model cards, continuous monitoring)
- responsible AI (transparency, fairness, policy compliance)

Source: [AWS exam guide · Content Domain 3](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01-domain3.html)

## Suggested study order

1. **3.1**: Bedrock Guardrails and defence in depth. This is the most frequently tested topic in the domain.
2. **3.2**: network isolation, encryption and PII. These build on [Task 2.3](../domain-2-implementation-integration/03-task-2.3-enterprise-integration-architectures.md).
3. **3.3 → 3.4**: governance, audit and monitoring first, then the responsible AI principles that they enforce.
