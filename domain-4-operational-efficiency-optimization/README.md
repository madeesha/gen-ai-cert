# 📙 Domain 4 · Operational Efficiency and Optimization for GenAI Applications (12%)

Domain 4 covers running GenAI applications efficiently. It covers cost (token efficiency, model tiering, throughput and caching), performance (latency, retrieval speed, inference parameters, resource allocation) and GenAI-specific monitoring (token and quality metrics, tool and agent observability, vector store operations, failure-mode troubleshooting).

Source: [AWS exam guide · Content Domain 4](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01-domain4.html)

## Suggested study order

1. **4.1**: cost levers (tokens, model choice, batch and service tiers, caching). Exam questions often ask for the most cost-effective option.
2. **4.2**: latency and throughput levers, and how to choose inference parameters.
3. **4.3**: CloudWatch metrics, invocation logs, tracing, and the GenAI failure modes they help you find.
