# 📗 Domain 2 · Implementation and Integration (26%)

Domain 2 is the second most heavily weighted domain on AIP-C01. It covers building agentic systems and tool integrations, deploying FMs, wiring GenAI into enterprise environments, FM API integration (sync and async calls, streaming, resilience and routing), and the application patterns and developer tools that tie these together.

Source: [AWS exam guide · Content Domain 2](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01-domain2.html)

## Suggested study order

1. **2.4 → 2.2**: learn how applications call FMs (sync, async, streaming, retries, routing), then where the models run and how they are deployed.
2. **2.1**: agents, MCP and tool use. This is the largest task in the domain with 7 skills, and a frequent source of exam scenarios.
3. **2.3**: enterprise connectivity, identity, data residency, CI/CD and the GenAI gateway pattern.
4. **2.5**: UI, developer tooling and troubleshooting. This task connects the others.
