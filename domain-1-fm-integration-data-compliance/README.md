# 📘 Domain 1 · Foundation Model Integration, Data Management, and Compliance (31%)

Domain 1 is the most heavily weighted domain on AIP-C01. It covers designing GenAI solutions, choosing and running foundation models (FMs), preparing data for them, vector stores, retrieval (RAG), and prompt engineering and governance.

Source: [AWS exam guide · Content Domain 1](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01-domain1.html)

## Task statements

| Task | Title | Skills | Notes |
| --- | --- | --- | --- |
| 1.1 | Analyze requirements and design GenAI solutions | 1.1.1 – 1.1.3 | [01 · Requirements & solution design](01-task-1.1-requirements-solution-design.md) |
| 1.2 | Select and configure FMs | 1.2.1 – 1.2.4 | [02 · Select & configure FMs](02-task-1.2-select-configure-fms.md) |
| 1.3 | Implement data validation and processing pipelines for FM consumption | 1.3.1 – 1.3.4 | [03 · Data validation & processing](03-task-1.3-data-validation-processing.md) |
| 1.4 | Design and implement vector store solutions | 1.4.1 – 1.4.5 | [04 · Vector store solutions](04-task-1.4-vector-store-solutions.md) |
| 1.5 | Design retrieval mechanisms for FM augmentation | 1.5.1 – 1.5.6 | [05 · Retrieval mechanisms](05-task-1.5-retrieval-mechanisms.md) |
| 1.6 | Implement prompt engineering strategies and governance for FM interactions | 1.6.1 – 1.6.6 | [06 · Prompt engineering & governance](06-task-1.6-prompt-engineering-governance.md) |

## Suggested study order

1. **1.2 → 1.1**: learn which FMs and deployment options exist, then how to design solutions with them.
2. **1.3 → 1.4 → 1.5**: follow the data path from raw data to processing, vector stores and retrieval. This is the core of RAG and the largest block of skills.
3. **1.6**: prompts, conversation context, prompt governance and Prompt Flows.
