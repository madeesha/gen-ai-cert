# 📓 Domain 5 · Testing, Validation, and Troubleshooting (11%)

Domain 5 covers proving that GenAI applications work and fixing them when they don't. It covers evaluation systems (output quality metrics, Bedrock Model Evaluations, LLM-as-a-judge, RAG and agent evaluation, user feedback, quality gates, deployment validation) and troubleshooting (context overflow, API integration errors, prompt problems, retrieval issues, prompt maintenance).

Source: [AWS exam guide · Content Domain 5](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01-domain5.html)

| 5.2 | Troubleshoot GenAI applications | 5.2.1 – 5.2.5 | [02 · Troubleshooting](02-task-5.2-troubleshooting.md) |

## Suggested study order

1. **5.1**: evaluation. It has 9 skills, so take it in two sittings: skills 5.1.1–5.1.4 cover metrics, model evaluation, feedback and QA, and skills 5.1.5–5.1.9 cover RAG, retrieval, agents, reporting and deployment validation.
2. **5.2**: troubleshooting. Practise going from symptom to cause to fix. The scenario questions test exactly that.
